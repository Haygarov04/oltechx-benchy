# OLTechX Проверка

Програма за Windows, която проверява компютъра преди продажба в [OLTechX](https://www.oltechx.com):

- разпознава процесора, видеокартата, RAM паметта, дънната платка, дисковете (със SMART) и батерията на лаптоп;
- натоварва процесора и видеокартата и сверява всеки резултат с верния, за да хване нестабилен хардуер;
- проверява паметта на видеокартата за грешни клетки;
- качва резултата в акаунта ти и попълва обявата: целия компютър, една част или комплект.

## Свързване с акаунта

Без парола в програмата. Или натискаш „Свържи през браузъра“ и потвърждаваш в сайта, или въвеждаш кода от
`oltechx.com/proverka`. Ключът може само да качва проверки и се пази криптиран от Windows. Изключва се от
Настройки в сайта, при изход от програмата и сам, когато обявата за това устройство стане продадена.

## Сваляне

Последната версия: [OLTechX-Proverka-Setup.exe](https://github.com/Haygarov04/oltechx-benchy/releases/latest/download/OLTechX-Proverka-Setup.exe).

Програмата още не е подписана, затова Windows първия път показва „Windows защити компютъра ви“.
Натисни „Повече информация“ и „Изпълни въпреки това“.

## Разработка

```bash
npm ci
npm start
```

`OLTECHX_URL=http://localhost:3100 npm start` я свързва с локалния сайт. Нова версия: смени `version`
в `package.json`, после `git tag v0.1.1 && git push --tags`. GitHub Actions сглобява инсталатора.
